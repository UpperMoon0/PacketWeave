# PacketWeave 0.1.3

- Add `ContextualTransferRegistry<T>` for consumers that must pin authenticated transfer context such as gadget identity, active profile or destination policy.
- Reuse the core registry for byte limits, per-owner/global admission, expiry, authorization and chunk validation. Release pinned context on every terminal path.
- Cover completion, incomplete receives, duplicate chunks, expiry, authorization revocation, owner limits and disconnect/shutdown cleanup.
- Keep the complete API compatible with Java 8 across all native targets.
