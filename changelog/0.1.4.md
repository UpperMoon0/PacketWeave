# PacketWeave 0.1.4

- Add native Forge 1.12.2 and Fabric/NeoForge 26.2 artifacts. Retain the existing Fabric/Forge 1.16.5 lanes.
- Preserve the shared Java 8 transfer API, consumer-owned wire protocols, authorization, bounds and lifecycle semantics.
- Extend the independent build/release matrix to eleven native targets with legacy FML metadata and runtime bytecode checks.
- Exercise the shared core suite on Java 8, 17 and 25.

Native adapters expose the shared API; they do not introduce a new packet protocol. Consuming mods remain responsible for authenticated connections and cleanup.
